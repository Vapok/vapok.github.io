Heuristic Evaluation Framework & Standards

This transparency system measures every Valheim modification against a 5-dimension rubric to ensure compliance with Thunderstore's AI Generated policy. Any mod utilizing LLM-generated code, documentation, or assets must carry the AI Generated tag.

1. C# Source Code (Weight: 35%)
Scans decompiled assemblies for typical LLM prompt hallucination patterns, robotic method signatures, unnecessary wrapper redundancy, and dead logic branches.
2. Git Diffs & Commits (Weight: 20%)
Analyzes commit cadence, co-author markers (e.g. Co-authored-by: AI <bot@...>), automated pull request merges, and branch velocity.
3. Documentation & Readmes (Weight: 20%)
Audits package descriptions and readmes for generic LLM purple prose (e.g. "delve into the enchanting realm", "seamlessly elevates your journey").
4. Visual Assets (Weight: 15%)
Evaluates package icons and banners for synthetic diffusion artifacts, hypersaturated color banding, and lack of authentic in-game screenshot elements.
5. Author Stance (Weight: 10%)
Checks author public stance, repository contributing guidelines (such as ComfyMods canary traps), portfolio compliance percentage, and historical tag honesty.
