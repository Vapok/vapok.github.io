Heuristic Evaluation Framework & Standards

This transparency system measures every Valheim modification against a 5-dimension rubric to ensure compliance with Thunderstore's AI Generated policy. Any mod utilizing LLM-generated code, documentation, or assets must carry the AI Generated tag.

1. C# Assembly & Logic (Weight: 40%)
Audits decompiled assemblies for explicit LLM metadata attributes, remote AI completions endpoints (OpenAI, DeepSeek, Anthropic), prompt leaks, and binary C# structural heuristics.
2. Package Manifest & Structure (Weight: 20%)
Audits Thunderstore package manifest dependencies, modular DLL organization, automated CI/LLM scaffolding, and release structure.
3. Documentation & Copywriting (Weight: 20%)
Audits package descriptions and readmes for explicit tool disclosures and formulaic LLM template copywriting.
4. Visual & Audio Media (Weight: 20%)
Evaluates binary image/audio/UnityFS headers for AI generator signatures (Stable Diffusion, ComfyUI, ElevenLabs, Meshy) and headless C# procedural audio/texture/mesh synthesis.
5. Author Portfolio & Stance (Informational — 0% Weight)
Displays factual catalog statistics on Thunderstore (ratio of declared AI packages). Strictly informational — never used to penalize or flag individual mods.
⚡ Updates Every 30 Minutes
Synchronized every 30 minutes. As authors publish or update packages, new audits are indexed automatically.
