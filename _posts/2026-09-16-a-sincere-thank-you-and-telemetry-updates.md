## Introducing Lightweight Anonymous Telemetry

Starting with the latest core updates, you will notice a new startup splash screen and an **Anonymous Telemetry** system built into my mods.

### Why was this added?
As thousands of players install and update mods across different game versions, it can be tough to know which versions are in active use, how smoothly they are running, and where game patches might be causing silent conflicts. 

This lightweight ping helps me:
1. **Track active usage counts** and version adoption so I know which mods need immediate patch attention.
2. **Identify stability issues** and ensure newer updates aren't breaking existing setups.
3. **Prioritize new features** based on what the community actively plays.

---

## 100% Anonymous — Zero Personal Data

I believe in total transparency. Here is exactly how this data is handled:

* **What IS tracked:** Basic metadata like the mod name, mod version, game version, and a temporary random session identifier to count active users.
* **What is NEVER tracked:** 
  * ❌ No Steam IDs, account names, or usernames.
  * ❌ No personal information or contact details.
  * ❌ No hardware profiling or serial numbers.
  * ❌ No save files, character data, inventory contents, or gameplay chat logs.

For full details, you can review my updated [Privacy Policy](/privacy-policy/).

---

## Total Control: How to Opt Out

Your autonomy matters. While anonymous data helps guide development, telemetry is completely optional. If you prefer to disable it, you can easily opt out at any time:

1. Open your mod’s configuration file (`BepInEx/config/`) or use the in-game **Configuration Manager** (`F1`).
2. Set **`Enable Anonymous Telemetry`** to **`false`** (or uncheck the box).

Disabling telemetry will never lock or limit any gameplay features—all mod functionality remains 100% available.
